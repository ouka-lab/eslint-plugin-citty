# eslint-plugin-citty

ESLint plugin for [citty](https://github.com/unjs/citty).

## Installation

```bash
npm install -D eslint-plugin-citty
```

## Usage

Add `citty` to the plugins section of your `.eslintrc` configuration file. You can omit the `eslint-plugin-` prefix:

```json
{
    "plugins": [
        "citty"
    ]
}
```
